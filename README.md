# ml-thinking-notes

This repository is a personal collection of notes and small experiments
that record how I actually understand machine learning concepts.

It is **not** a complete tutorial or a summary of textbooks.
Most notes here come from my learning process in courses like COMP9417,
including assignments, exams, and mistakes I made along the way.

The goal of this repo is simple:

> Write things down only after I truly understand them.

## Structure

- `concepts/`  
  Core machine learning ideas explained in my own words.
  - [Confusion Matrix](concepts/confusion-matrix.md)

- `recipes/`  
  Practical patterns I often reuse (data splitting, preprocessing, etc.).

- `notebooks/`  
  Small experiments to verify intuition with code.

- `mistakes/`  
  Things I misunderstood before, especially common exam traps.

  - [Bias vs Variance](concepts/bias-variance.md)
